## Daily workflow
1. Learn a concept.
2. Build something with it.
3. Test and debug the implementation.
4. Explain what you learned.
5. Record evidence and the next step.

## Completion rule
A day is complete only when its work and evidence have been reviewed.
A Git commit alone does not prove completion.
